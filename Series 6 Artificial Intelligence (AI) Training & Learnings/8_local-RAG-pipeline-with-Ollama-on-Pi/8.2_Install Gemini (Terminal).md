# Install Gemini AI (Terminal) in Less Than 3 Minutes
# ---------------------------------------------------
# 🍎 Step-by-Step: Install Gemini on macOS #
# -----------------------------------------------
# 🧰 Prerequisites
Make sure you have:
macOS 10.15+
Node.js v18+ (Install via Homebrew: brew install node)
npm (comes with Node.js)
Google account with Gemini access!!

# 🚀 Install Gemini CLI
npm install -g @google/gemini-cli
This installs the gemini command globally.

# ⚙️ Optional: Create new folder
mkdir my-test-project

# 🔐 Authenticate
Run:
gemini login
This opens a browser window to authenticate with your Google account.
Once done, your terminal is linked to Gemini.

# NOTE: If you see the following:
Please set an Auth method in your /Users/<username>/.gemini/settings.json or specify one of the following environment variables before running: GEMINI_API_KEY, GOOGLE_GENAI_USE_VERTEXAI, GOOGLE_GENAI_USE_GCA

Get API Key from:
https://aistudio.google.com/app/api-keys

Then ...
/Users/<username>/.gemini/settings.json

And include ...
{
  "auth": {
    "api_key": "your_api_key_here"
  }
}

Restart terminal window. Try it again!

Was not working for me, so created it like this:
export GEMINI_API_KEY="<your_api_key_here>"

More Information here:
https://ai.google.dev/gemini-api/docs/api-key

# OR
# -----

# Logout and back in with (uses API Key from above that was already set!)
gemini

# Benefits of Terminal!
Have a look at the model ... provides the latest & greatest! gemini-2.5-pro
Tells you the context you have left for the window (browser hides by default!) e.g. 99%
Can reload the context of the previous conversation using the gemini.md file
Gemini will wait for user confirmation to be able to access resources!

# 🛠️ First Commands
Try these to get started:
gemini ask "Explain this Python function"
gemini edit index.js --ask "Add error handling"
gemini shell "List all Docker containers"
You can use natural language to write code, run shell commands, debug, and more.

# ⚙️ Optional Configs
.geminiignore to exclude files from context
settings.json for CLI behavior
/rewind to undo changes
@ for context commands, ! for shell commands
