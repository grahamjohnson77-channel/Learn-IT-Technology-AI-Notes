# Install Claude Code (Terminal) in Less Than 3 Minutes
# -----------------------------------------------------
# 🍎 Step-by-Step: Install Claude Code on macOS #
# ------------------------------------------------
1. Create Claude FREE account on claude.ai
Make sure you have an account created! Allows you to test claude.ai prompts in browser for practice!

Claude Code is Claude in the terminal ...

BUT Claude PRO subscription can be used for Claude Code :)
    (Can be around $20 per month. But you can get subscription to add credits & API Key)

Claude PRO subscription is recommended but simple credits for testing can help!

2. Install Node.js (if not already installed)
# Claude Code requires Node.js version 18 or newer. You can install it via Homebrew:
brew install node

node --version
v22.9.0

npm --version
10.8.3

3. Install Claude Code globally
# npm (comes with Node.js)
npm install -g @anthropic-ai/claude-code
This gives you access to the claude CLI from anywhere in your terminal.

# Check if installed
npm ls @anthropic-ai/claude-code

# IF you needed to uninstall (see notes below!)
npm uninstall @anthropic-ai/claude-code

4. Authenticate with Anthropic
claude login
Paste your Anthropic API key when prompted. You can get one from console.anthropic.com.

5. Start using Claude Code
Try commands like:
claude explain index.js
claude edit app.py --ask "Add error handling"
claude git status

6. Some popular commands
/init               <- Sets up basic configurations
/content            <- Shows current usage stats e.g. tokens etc
/agents             <- Create a new project for agent

# ------------------------------------------------
6. If you need to UNINSTALL Claude AI to reinstall
rm -rf ~/.claude
rm -f ~/.claude.json

You can also check for other config files:
ls ~/.config | grep claude

npm uninstall -g claude
npm install -g claude

Add API Key. You can export it directly in your shell:
export ANTHROPIC_API_KEY="your-new-key-here"
Or add it to your shell profile (~/.bashrc, ~/.zshrc, etc.) for persistence.

More details here: https://ctok.ai/en/claude-code-uninstall
